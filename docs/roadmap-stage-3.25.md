# Aşama 3.25 — Görsel coğrafi katmanlar

Durum: geliştirme aşamasında

Hedefler:

- küre ve azimutal kartografik görünümde kıta / ülke sınırlarını isteğe bağlı göstermek
- mevcut ızgarayı kullanıcı kontrollü görsel katmana dönüştürmek
- görsel katman durumunu fiziksel model hesap motorundan ayrı tutmak
- tanımlı düzlem modeline tanımsız küresel coğrafi projeksiyon uydurmamak
- sonraki topografya ve gece ışıkları katmanları için ortak katman sözleşmesi oluşturmak
